### BUS 104

Hello and welcome to **BUS 104**!  

This public GitHub repository is the official home for all lecture materials. Everything we use in class — lecture notes, Excel workbooks, Python scripts, data files, and any other supporting resources — will be posted here.

---

### Repository Structure

Lecture materials are organized into **separate folders**, one per lecture.  

**Folder naming convention:**  
`Week XX - Short Topic Title`

**Examples:**
- `Week 01 - Course Introduction and Overview`
- `Week 02 - Analytics Primer`

**Inside each lecture folder you will find:**
- Lecture notes or slides (usually PDF)
- Excel spreadsheets (`.xlsx`)
- Python code files (`.py`)
- Data files (`.csv`, `.xlsx`, etc.)
- Any other files or resources used in that class

### How to Download Files

#### Option 1: Download the Entire Repository (Recommended)
1. On the main page of this repository, click the green **Code** button (top right).
2. Select **Download ZIP**.
3. Unzip the file on your computer.

This is the easiest way to get everything at once.

#### Option 2: Download a Single File
1. Navigate into the desired lecture folder.
2. Click on the file you want.
3. On the file preview page, click the **Download raw file** button (↓ icon in the top-right corner).

#### Option 3: Download an Entire Lecture Folder
1. Open the lecture folder.
2. Click the green **Code** button at the top of the folder.
3. Select **Download ZIP**.
